# YachtJet

Концепт лендингу сервісу оренди люксових яхт. Проєкт демонструє адаптивну верстку, презентацію послуг і флоту, а також інтерфейс форми бронювання.

## Про проєкт

YachtJet — односторінковий сайт із темним морським візуальним стилем. Сторінка послідовно знайомить відвідувача з брендом, яхтами та можливостями відпочинку, а потім пропонує залишити заявку.

### Можливості

- адаптивне компонування для різних розмірів екрана;
- мобільне меню з керуванням клавіатурою та доступними атрибутами;
- секції про сервіс, каталог яхт, активності, бронювання та відгуки;
- форма з базовою браузерною валідацією;
- SVG-зображення та іконки в оформленні сторінки.

> Це портфоліо-демонстрація: форма бронювання та кнопки не підключені до серверної логіки.

## Технології

- HTML5
- CSS3
- JavaScript (без фреймворків)

## Запуск

Клонувати репозиторій і відкрити `index.html` у браузері. Для локального сервера можна скористатися розширенням **Live Server** у Visual Studio Code.

## Структура

```text
.
├── index.html     # Розмітка сторінки
├── index.css      # Стилі та адаптивні правила
├── menu.js        # Логіка мобільного меню
└── images/        # Ілюстрації та SVG-іконки
```
